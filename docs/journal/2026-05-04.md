## 🐛 Problèmes, Bugs & Régressions rencontrés
- **Astro/React Hydration — Non-Serializable Props** : L'injection de callbacks ou fonctions JavaScript depuis un fichier `.astro` vers un composant React hydraté (`client:load`) échoue systématiquement (les props fonctions arrivent `undefined` côté client, empêchant le fonctionnement du bouton `SlideToJoin`).
- **Build Failure — JSX in Astro Frontmatter** : L'instanciation de composants JSX (comme `<IconHome />`) dans le bloc TypeScript frontmatter d'Astro pour alimenter les listes du `FloatingDock` a déclenché une erreur fatale Vite : `Expected ">" but found "className"`.
- **Lucide-React Export Inconnu** : Erreur de compilation suite à l'import de `<Tool />` au lieu de `<Wrench />`.
- **ReferenceError `target is not defined`** dans `IconContainer` (commit `1a3c08da`, v1.7.8), bloquant le pré-rendu statique SSG.
- **Opacité zéro au chargement SSR** : Utilisation de wrappers d'animation `FadeIn` masquant le contenu au premier rendu si `client:visible` n'est pas déclaré.
- **Ruptures de contraste lors du rétrofit Mode Clair** : Encarts textuels, cartes OUI/NON et tooltips du dock devenus illisibles lors de la première bascule en mode clair.

## 💡 Solutions retenues & Arbitrages techniques
- Isolation de l'interactivité dans des composants React autonomes : transfert de l'événementiel (`window.open`) et passage de chaînes primitives (`href`, URLs) dans les props.
- Déclaration des éléments React complexes via `React.createElement` ou gestion interne dans des fichiers `.tsx` dédiés.
- Validation systématique des noms d'exports d'icônes sur la documentation officielle `lucide.dev`.
- Application d'un smooth scroll global au CSS et harmonisation des curseurs `cursor-pointer` sur l'intégralité des éléments interactifs.
- Décision d'arbitrage produit : Suppression du calculateur de rentabilité pour maintenir un parcours utilisateur direct, centré sur la promesse métier et le CTA à 29€.
- Mise en œuvre de l'API native `document.startViewTransition` pour orchestrer le basculement de thème sans scintillement.
- Capitalisation dans la bibliothèque Antigravity : extraction de `SlideToJoin` et `LiquidSwitch`.

## ⚠️ Points de vigilance pour le futur
- Ne jamais passer de fonctions callbacks d'Astro vers React.
- Conserver des styles de conteneurs explicites pour les cartes informatives lors des ajustements de thèmes (éviter le piège du texte foncé sur fond sombre).
